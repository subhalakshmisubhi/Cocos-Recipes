# Cocos-Recipes

A web-based recipe management and culinary learning platform designed to streamline recipe storage, ingredient filtering, nutritional tracking, and workshop enrollments.

## 🚀 Key Features
* **Recipe Management:** Securely upload, view, and manage recipes with detailed preparation steps and ingredients.
* **Advanced Search & Filter:** Instantly look up recipes by keywords, ingredients, or titles.
* **Nutritional Insights:** View built-in calorie counts and dietary breakdowns for dishes.
* **Workshop System:** Explore integrated cooking courses and mentor-led workshops.

## 🛠️ Tech Stack
* **Backend:** Python (Flask)
* **Database:** SQL
* **Frontend:** HTML5, CSS3, JavaScript
